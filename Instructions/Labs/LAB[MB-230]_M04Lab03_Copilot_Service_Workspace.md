# Practice Lab – Use Copilot Service workspace

## Scenario

As a service representative at Contoso Coffee, you use Copilot Service workspace to handle customer cases. In this lab, you validate the experience profile configured in the preceding lab, use productivity tools, move among application tabs, and manage multiple case sessions. This exercise should take approximately 20 minutes to complete.

> [!IMPORTANT]
> Complete the preceding representative experience profile lab before you begin. Confirm that your current user has the **Productivity tools user** security role, is assigned to **CS Temp**, and that the profile includes **Entity Temp**, **Customer Summary**, **Knowledge search**, and **Agent scripts**.

## Exercise 1 – Validate the representative experience

### Task 1 – Open a configured case session

1. Use the app selector to open **Copilot Service workspace**.

1. Refresh the browser before opening a case so that the workspace loads the security-role and profile changes from the preceding lab.

1. In the site map, select **Cases**.

1. Select the **My Active Cases** view.

1. Open **Coffee Brewer Still Not Heating After Reset**.

1. Confirm that a case session opens in the session pane and that the session title uses the case title.

1. Confirm that **Customer Summary** is available as an application tab in the session.

### Task 2 – Use productivity tools

1. In the productivity pane, select **Knowledge search**.

1. Enter `Coffee Brewer Not Heating` in the search box.

1. Open the **Coffee Brewer Not Heating** knowledge article from the search results.

1. Review the article, and then return to the case tab.

1. In the productivity pane, select **Agent scripts**.

1. Select **Script 1** if it isn't already selected.

1. Confirm that **Step 1** displays **Hi, how can I help you today?**

## Exercise 2 – Navigate application tabs and sessions

### Task 1 – Work with application tabs

1. On the **Coffee Brewer Still Not Heating After Reset** case, select **Relecloud** in the **Customer** field.

1. Confirm that the account opens as an application tab in the current case session.

1. Select the **Customer Summary** tab.

1. Press the Tab key to move through the interactive controls in the tab.

1. Press Shift+Tab to move to the preceding control.

1. Press Enter on a selected control to activate it, and then return to the case tab.

> [!NOTE]
> Opening related records creates application tabs within the current session. It doesn't create another case session.

### Task 2 – Open a second case session

1. In the session pane, select the **Home** session.

1. In the site map, select **Cases**.

1. Select the **My Active Cases** view.

1. Open **Annual Maintenance Required**.

1. Confirm that a second case session appears in the session pane.

1. Select each case session and confirm that its tabs and productivity-pane context are separate from the other session.

### Task 3 – Close the case sessions

1. Select the **Annual Maintenance Required** session.

1. Select **Close the session**.

1. Confirm the action if prompted.

1. Select the **Coffee Brewer Still Not Heating After Reset** session.

1. Select **Close the session**, and then confirm the action if prompted.

1. Confirm that the **Home** session remains available.
